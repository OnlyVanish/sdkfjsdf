# پروژه اندروید Crow

این پروژه پوسته‌ی مستقل اندروید با Kotlin را برای اجرای بازی Crow دارد. فایل HTML/Canvas در WebView امن مبتنی بر `WebViewAssetLoader` اجرا می‌شود؛ محتوای بازی و گرافیک اصلی حفظ شده‌اند.

## نسخه‌ی Server-Driven 1.5

- هیچ مرحله‌ی قابل‌بازی داخل APK تعبیه نشده است؛ حتی ۱۶ پرونده‌ی آغازین از سرور دریافت می‌شوند.
- در اولین راه‌اندازی سرور تازه، بسته‌ی اصلی ۱۶ مرحله‌ای به‌صورت خودکار از فایل seed تعبیه‌شده در Go Server منتشر می‌شود.
- اپ هنگام شروع، فصل فعال را از API سرور می‌گیرد، SHA-256 را بررسی می‌کند و آن را در حافظه‌ی خصوصی گوشی نصب می‌کند.
- سرور فقط یک فصل فعال دارد. هر ZIP تازه‌ای که از پنل منتشر شود، جایگزین کامل فصل قبلی می‌شود؛ مراحل تازه از شماره‌ی ۱ آغاز می‌شوند.
- در اجرای بعدی اپ، بسته‌ی تازه به‌طور خودکار جایگزین بسته‌ی ذخیره‌شده‌ی گوشی و پیشرفت فصل قبلی پاک می‌شود.
- بسته‌ی دانلودشده برای اجرای آفلاین موقت در حافظه‌ی گوشی کش می‌شود؛ بنابراین قطع موقت اینترنت محتوایی را که قبلاً با موفقیت دریافت شده از بین نمی‌برد.
- در صورت خالی‌بودن فهرست سرور، بسته‌ی محلی هم پاک می‌شود و بازی بدون فصل فعال اجرا نخواهد شد.

راهنمای ساخت بسته‌ی جدید در `CROW_SEASON_PACKS_FA.md` و راه‌اندازی سرور در `crow-server/README_FA.md` است.

## انتشار نسخه‌ی برنامه و امضا

سرور علاوه بر فصل‌ها می‌تواند APK رسمی را نیز منتشر کند. نسخه‌های قدیمی که updater ندارند باید یک‌بار APK دارای updater را دستی نصب کنند. برای نصب به‌روزرسانی روی نسخه‌ی موجود، APK جدید باید با همان کلید امضای خصوصی نسخه‌ی نصب‌شده امضا شود. keystore اصلی داخل ZIP ارسالی نبود؛ از دست‌رفتن آن مانع ساخت به‌روزرسانی سازگار با نصب قبلی می‌شود.

## ساخت با Android Studio در ویندوز

1. ZIP را استخراج کن و پوشه‌ی پروژه را در Android Studio با **Open** باز کن.
2. JDK 17 یا بالاتر و Android SDK Platform 36 را نصب داشته باش.
3. پس از Gradle Sync از مسیر **Build → Build Bundle(s) / APK(s) → Build APK(s)** خروجی بگیر.

یا در PowerShell از ریشه‌ی پروژه اجرا کن:

```bat
gradlew.bat assembleDebug
```

خروجی Debug:

`app/build/outputs/apk/debug/app-debug.apk`

## جزئیات فنی

- Application ID: `com.crow`
- نام برنامه: `Crow`
- زبان پوسته: Kotlin
- حداقل Android: API 23
- Compile SDK / Target SDK: 36
- Gradle: 8.13
- Android Gradle Plugin: 8.13.2
- Kotlin: 2.2.0

هسته‌ی گرافیکی و منطق بازی HTML/Canvas است و در WebView اجرا می‌شود؛ این پروژه تبدیل کامل بازی به رابط Native Compose نیست.

## آیکون بازی

آیکون لانچر بازی در مسیر `app/src/main/res/mipmap-*` قرار دارد. تصویر منبع در `artwork/crow_game_icon_source.png` نگهداری می‌شود.

## ساخت نسخه‌ی Release امضاشده

فایل `keystore.properties` را در ریشه‌ی پروژه بساز:

```properties
storeFile=C:/path/to/your-key.p12
storePassword=رمز-keystore
keyAlias=نام-alias
keyPassword=رمز-کلید
```

سپس اجرا کن:

```bat
gradlew.bat assembleRelease
```

خروجی: `app/build/outputs/apk/release/app-release.apk`

این فایل در `.gitignore` است؛ keystore و رمزهایش را داخل Git یا ZIP عمومی قرار نده.
